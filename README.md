# React Crypto Dashboard

A real-time cryptocurrency price dashboard built with React and Vite. Track live prices, market caps, and price changes for popular cryptocurrencies in a clean, responsive interface.

## Features

- Live cryptocurrency price tracking
- Market cap and 24h price change indicators
- Search and filter coins
- Responsive design for desktop and mobile

## Tech Stack

- React
- Vite
- JavaScript (ES6+)

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/jerichoNega/react-crypto-dashboard.git

# Navigate into the project
cd react-crypto-dashboard

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173`.

## Build

```bash
npm run build
```
